Slot Classifier — 新使用者上手指南

從零開始，到第一份競品報告出爐的完整操作步驟。

更新：2026-06-09 分支：perf/cpu-optimize-ocr Python 3.10 Claude Code CLI CPU-only
完整流程概覽 Phase 1：環境安裝 Phase 2：Skill 安裝 Phase 3：執行分析 Phase 4：審核修正 Phase 5：競品報告 常見問題

完整流程概覽

每次分析一款競品遊戲的完整路徑：

① 放入影片
→
② 啟動 claude
→
③ 確認 ROI
→
④ 自動分類
→
⑤ 瀏覽器審核
→
⑥ 競品報告

步驟 ③～⑥ 全部由 Claude 在對話中協調，不需要手動執行任何指令。

一次安裝，之後每款遊戲只需：把 mp4 放進資料夾 → 打開 claude → 輸入「幫我分析 XXX」。
⚙️ Phase 1 — 環境安裝（只做一次）

1. 取得專案

1
Clone 專案並切換到工作分支 
git clone https://github.com/Ashley860511/slot-classifier.git
cd slot-classifier
git checkout perf/cpu-optimize-ocr
Windows 使用者：建議把資料夾放到短路徑（如 D:\slot-classifier）， 避免 PaddleOCR 安裝時因路徑過長失敗。
2
安裝 Python 3.10

前往 python.org 下載 Python 3.10，安裝時勾選 Add python.exe to PATH。

python --version   # 確認顯示 Python 3.10.x
3
建立虛擬環境並安裝套件 
# macOS / Linux
python3.10 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt

# Windows PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt

安裝時間約 5～15 分鐘（PaddleOCR 套件較大）。

Windows PowerShell 若出現「無法載入 .ps1」：先執行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
4
確認 Python 環境正常 
python check_environment.py

看到各套件版本無誤即完成。

5
安裝 Node.js（Claude Code 前置）

前往 nodejs.org 下載 LTS 版（18 以上）。

node --version   # 需顯示 v18.x 以上
6
安裝 Claude Code 並登入 
npm install -g @anthropic/claude-code
claude login   # 在瀏覽器完成帳號綁定，回到終端即完成
claude --version   # 確認安裝成功
🧩 Phase 2 — 安裝 slot-report Skill（只做一次）

安裝競品報告生成 Skill

Skill 是 Claude Code 的外掛，負責讀取分類截圖並自動生成 report.html 競品分析報告。 安裝說明在 claude/ONBOARDING.md，以下是快速流程：

1
找到 Claude Code 的 skills 資料夾

在 Claude Code 對話中輸入：

/skills

或直接前往（Windows）：

%APPDATA%\Claude\local-agent-mode-sessions\skills-plugin\<uuid>\<uuid>\skills\

macOS / Linux：

~/.claude/skills/
2
建立 slot-report 子目錄並複製 SKILL.md

在 skills 資料夾內新增 slot-report/，將 claude/ONBOARDING.md 內的 SKILL.md 內容貼入：

skills/
└── slot-report/
    └── SKILL.md   ← 從 claude/ONBOARDING.md 複製內容
3
重新啟動 Claude Code

關閉並重開 claude，Skill 即可使用。

驗證：在 Claude Code 輸入 /skills，看到 slot-report 列出即安裝成功。
🎬 Phase 3 — 執行分析（每次使用）

開始分析競品遊戲

1
把影片放入 input_videos/ 
project/input_videos/WildTrain.mp4

支援 .mp4，檔案名即為輸出資料夾名稱，建議使用英文。

2
在專案根目錄啟動 Claude Code 
cd slot-classifier
claude
3
告訴 Claude 開始分析 
幫我分析 WildTrain

Claude 會自動確認影片存在，然後執行 Auto ROI 偵測。

4
確認 ROI 邊框

Claude 輸出 WAITING_ROI_CONFIRM: 後，會告知你一個本機路徑：

project/output/WildTrain/_debug/roi_adjust.html

用瀏覽器開啟，檢查綠色邊框是否對齊遊戲畫面：

情況操作回覆 Claude
邊框位置正確 不需調整 ROI OK
邊框需要調整 拖曳四角/側邊 → 按「✅ 確認 ROI」→ 貼上複製的座標 ROI 確認：400,50,650,950
5
等待分類完成

Claude 收到 ROI 確認後自動執行：

  1. 截圖分類（Basegame / Feature / BigWin / Transition / Result / Help…）
  2. 計算信心分數（high / medium / low）
  3. 從 Help 頁自動提取 Symbol 圖
  4. 生成 review.html 審核頁
  5. 啟動本機審核 Server（http://localhost:8765）

4 分鐘影片約需 5～10 分鐘（CPU-only 環境）。首次執行會額外下載 PaddleOCR 語言模型（約 300 MB）。

🔍 Phase 4 — 人工審核修正

在瀏覽器審核截圖與 Symbol

分類完成後，Claude 會告知你開啟 http://localhost:8765。

Part A：截圖分類審核

信心等級標籤建議動作
high🟢 綠色直接跳過，分類確定
medium🟡 黃色快速掃一眼，有問題再修正
low🔴 紅色建議確認，視情況改分類或排除

每張卡片可操作：

  • ✅ 正確：標記確認，不移動檔案
  • 🔀 改分類：選正確類別，套用後截圖移到對應資料夾
  • 🗑️ 排除：移到 excluded/，從統計中移除

全部處理後按「套用修正」，CSV 與截圖自動更新。

Part B：Symbol 審核（頁面最底部）

捲到 review.html 最底部，可以看到 Symbol 審核區塊：

  1. 上方格子顯示已自動提取的 Symbol 圖，確認是否完整
  2. 若有遺漏（例如某張麻將牌、特殊符號）：
    → 點擊下方 Help 截圖縮圖
    → 在彈出的裁切工具上拖曳框選遺漏的 symbol
    → 輸入名稱（選填）→「✅ 加入為 Symbol」
localhost 環境（直接使用）：點擊「加入」後自動儲存到 symbol_table/symbols/symbol_manual_001.png，不需手動操作。

非 localhost（網路磁碟 / file:// 開啟）：點擊後會下載 PNG，請手動放到 project/output/WildTrain/symbol_table/symbols/

完成後回報 Claude

兩項都完成後，Claude 會主動詢問你，回覆即可：

完成了 / 好了 / 可以開始報告
📄 Phase 5 — 競品報告生成

生成 report.html

1
Claude 自動生成報告

收到你的確認後，Claude 使用 slot-report skill 讀取分類截圖與 Symbol，生成：

project/output/WildTrain/report.html

報告包含三大段落：

  • 📊 符號賠率表：特殊符號（Scatter/Wild）、主力符號、低值符號
  • 🃏 玩法機制：觸發條件、特效規則、連鎖機制
  • 🗺 遊戲流程圖：主遊戲 + Free Spin 雙列橫向流程
2
確認 Claude 列出的「待核對欄位」

Claude 生成後會主動列出以下欄位，請對照 Help 頁截圖逐一確認：

欄位來源建議確認方式
開發商畫面 Logo 推測對照片頭或 Help 頁 Logo
格局（Grid）截圖目測確認格柱數
最高倍率Free Spins 畫面 OCR對照 Help 頁數值
賠率數字OCR 讀取 Help 頁可能有誤讀，需人工核對
Wild 規則Help 文字推斷確認觸發條件
3
在瀏覽器開啟報告並編輯（選做）

用瀏覽器開啟 report.html，點擊右上角「✏️ 編輯模式」：

  • 點擊圖片 → 替換為其他截圖
  • 點擊文字 → 直接修改
  • 修改後自動回寫 tags.json 與 assets.json（localhost 環境）

常見問題

Q: Windows 下執行 .sh 腳本出錯

Claude Code 的對話觸發不需要你手動跑 .sh。若真的需要手動執行，請用 Git Bash 或 WSL，不是 PowerShell。

Q: PaddleOCR 安裝失敗（Windows Long Path）

  1. 把專案移到短路徑，如 D:\slot-classifier
  2. 刪除 .venv 後重新建立

若仍失敗，以系統管理員執行：

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
  -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

Q: PaddleOCR 分開安裝

pip install paddlepaddle==2.6.2
pip install paddleocr==2.7.3

Q: 第一次跑很慢（幾分鐘沒動靜）

首次執行 PaddleOCR 會自動下載語言模型（約 300 MB），需要網路連線，屬正常現象。

Q: review server port 8765 已被占用

告知 Claude：「請用 port 8766 啟動 server」，或手動：

.venv/bin/python review_server.py --video-id WildTrain --port 8766

Q: Symbol 只提取到 0 或 1 個

原因通常是 Help 頁只截到規則頁（文字頁），沒有截到賠率表（圖示頁）。 在 review.html Symbol 審核區塊，點擊 Help 截圖，手動框選遺漏的 symbol。

Q: 想重新分類（重跑整個流程）

直接對 Claude 說：

刪掉 WildTrain 的輸出，重新分析

Claude 會確認後刪除 project/output/WildTrain/，重新執行。

Q: 取得最新版本

git fetch origin
git pull origin perf/cpu-optimize-ocr

Q: slot-report Skill 找不到

確認 skills/slot-report/SKILL.md 存在，重新啟動 Claude Code。 詳細安裝說明在 claude/ONBOARDING.md。

效能參考

設定預設值說明
FRAME_INTERVAL20 幀取 1 張調高可加快速度，調低可提升截圖密度
OCR_MAX_SIDE480 pxOCR 輸入上限，自動縮圖後還原座標
cpu_threads2 核心限制 PaddleOCR 佔用，避免主機過載

調整取樣密度：修改 app/constants.py 的 FRAME_INTERVAL。
