Slot 遊戲分類器使用說明

這份文件整理目前 slot_classifier_figma_share_package 的日常使用方式：如何準備 Python 環境、放入影片、執行分類、查看輸出、產生 symbol 圖，以及匯出 Figma / FigJam 研究看板素材。

更新日期：2026-05-15 適用 Windows Python 3.10 建議 OpenCV + PaddleOCR 分類 + Symbol 裁切 + Figma 匯出
最快使用流程 資料夾用途 環境安裝 執行分類 輸出結果 Symbol 圖輸出 Figma 匯出 常見問題 參考文件

最快使用流程

  1. 把影片放進 project\input_videos。
  2. 第一次使用先執行 setup_venv.ps1 安裝 Python 套件。
  3. 用 check_environment.ps1 確認環境可用。
  4. 雙擊 run_classify_and_symbols.bat，或在 PowerShell 執行它。
  5. 到 project\output 查看每支影片的分類截圖、CSV 和 symbol 輸出。
  6. 需要 Figma / FigJam 看板時，再執行 run_figma_export.ps1。
一般使用者建議優先用 run_classify_and_symbols.bat。它會用專案內的 .venv 執行 app\main.py，跑完後輸出會集中在 project\output。

資料夾用途

位置 用途
app\main.py 主要分類器。讀取影片、擷取影格、OCR 判斷、分類截圖、挑選代表圖，並可接續處理 symbol 圖。
app\generate_symbol_table.py 從 Help / Paytable 畫面偵測 symbol，輸出 symbol PNG、contact sheet 和 HTML 檢查頁。
project\input_videos 放入要分析的 slot 遊戲錄影。建議使用 .mp4。

figma_tools Figma / FigJam 匯入工具，包含匯出 manifest 的 Python 腳本與 Figma Desktop plugin。
figma_export 執行 Figma 匯出後產生的素材包，包含 figma_manifest.json 和代表截圖。
.venv 本專案專用 Python 環境。若環境壞掉，可以刪除後重新執行 setup_venv.ps1。

環境安裝

1. 建議版本

建議使用 Python 3.10。目前套件鎖定如下：

numpy==1.26.4
opencv-python==4.6.0.66
paddlepaddle==2.6.2
paddleocr==2.7.3

不建議直接使用 NumPy 2.x 或 Python 3.12，因為 PaddleOCR / PaddlePaddle 在 Windows 上較容易遇到相容性問題。

2. 安裝套件

在專案資料夾開啟 PowerShell：

cd C:\Users\ashleyli\Documents\Codex\2026-04-30\files-mentioned-by-the-user-main\slot_classifier_figma_share_package
.\setup_venv.ps1

3. 檢查環境

.\check_environment.ps1

這會檢查 Python、OpenCV、PaddleOCR 等套件是否能正常載入。

若安裝 PaddleOCR 時出現 Windows Long Path 或路徑過長錯誤，建議把整個資料夾搬到較短路徑，例如 D:\slot_classifier_figma_share_package 或 C:\slot_classifier_figma_share_package，再重新建立 .venv。

執行分類

方式 A：雙擊批次檔

把影片放入 project\input_videos 後，雙擊：

run_classify_and_symbols.bat

這會處理 input 資料夾內的所有影片。

方式 B：用 PowerShell 執行

.\run_classifier.ps1

這會直接執行 app\main.py，使用專案內的 .venv\Scripts\python.exe，如果找不到才會改用系統 Python。

方式 C：只跑指定影片

如果只想跑單一影片，可以用影片檔名 stem 指定。假設影片是 Perfect Strike.mp4：

.\run_classify_and_symbols.bat "Perfect Strike"

方式 D：傳入進階參數

批次檔會把 -- 開頭的參數轉交給 app\main.py。例如：

.\run_classify_and_symbols.bat --video-id "Perfect Strike" --symbol-debug
.\run_classify_and_symbols.bat --skip-symbols

輸出結果

分類完成後，主要結果會出現在：

project\output\<video_id>\
輸出 說明
Basegame 主遊戲畫面，通常包含 spin、auto、下注、餘額等底部 UI。
Feature game Free game、Bonus、Remaining Free Spins 等正在進行中的特色遊戲畫面。
BigWin Big Win、Mega Win、Super Win、Jumbo Win 等大獎畫面。
Transition 進入或離開 feature 的轉場，例如 Start、Continue、Confirm。
Result Total Win、Collect、You've won 等結算畫面。
Help 規則說明、Paytable、Symbol Payout Values 等頁面，也是 symbol 裁切的主要來源。
Feature Buy 購買 feature 的彈窗或入口畫面。
loading 載入頁、logo、進度條、授權資訊等。
Other 無法穩定歸類或不適合研究看板的畫面。
low_score 低信心或品質較差的圖片，保留給人工檢查。
classification_result.csv 分類紀錄，包含每張候選圖的分類、分數與 OCR 資訊。

Symbol 圖輸出

目前分類器已和 generate_symbol_table.py 整合。分類完成後，工具會嘗試從 Help 或 low_score\Help 中找 Paytable 畫面，再裁切 symbol 圖。

常見輸出位置：

project\output\<video_id>\symbol_table\
project\output\<video_id>\symbol_table\symbols\
project\output\<video_id>\symbol_table\final_icons_contact_sheet.jpg

適合做什麼

  • 建立競品 symbol 素材庫。
  • 比較高低階符號、美術風格、特殊符號。
  • 整理成 Figma / FigJam icon board。
  • 後續人工命名、分級、標註。

可能需要人工檢查的情況

  • Paytable 圖上有大量 payout 數字貼近 symbol。
  • Help 頁是滾動式網頁，畫面只擷取到部分內容。
  • symbol 被特效、框線、文字遮擋。
  • 部分遊戲的 paytable 版面和一般 slot 差異很大。

Figma / FigJam 匯出

分類完成後，可以產生 Figma / FigJam 匯入用資料：

.\run_figma_export.ps1

輸出會在：

figma_export\
  figma_manifest.json
  images\

匯入 Figma / FigJam 的步驟：

  1. 開啟 Figma Desktop。
  2. 進入 Plugins，選擇 Development，再選 Import plugin from manifest...。
  3. 選取 figma_tools\figma_plugin\manifest.json。
  4. 開啟一個 Figma 或 FigJam 檔案。
  5. 執行 plugin：Slot Research Board Importer。
  6. 當 plugin 要求選資料夾時，選整個 figma_export 資料夾。
Figma 匯出預設保留每支影片的代表圖，例如 loading、Basegame、Transition、FreeGame、BUY FEATURE、Result。BigWin 會盡量保留最多三種代表大獎階段。Help 與 Other 不會放進 Figma 研究看板。

常見問題

PowerShell 無法執行 .ps1

如果系統阻擋 .ps1，可以用目前使用者範圍調整執行政策：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

安裝套件失敗或 PaddleOCR 無法安裝

  • 確認 Python 是 3.10。
  • 確認專案路徑不要太長。
  • 刪除 .venv 後重新執行 setup_venv.ps1。
  • 若公司網路或 VPN 擋住 pip 下載，需要切換網路或請 IT 協助。

分類結果太少或很多圖進 low_score

  • 先確認影片本身是否清晰，是否有完整遊戲畫面。
  • 檢查 classification_result.csv 內的分類與分數。
  • 查看 low_score，有些圖可能只是信心較低，仍可人工使用。
  • 若是特殊玩法，例如足球、卡牌、輪盤式 bonus，可能會被放進 Other。

Figma plugin 找不到圖片

  • 確認已先執行 run_figma_export.ps1。
  • 選資料夾時要選整個 figma_export，不是只選 images。
  • 確認 figma_export\figma_manifest.json 存在。
