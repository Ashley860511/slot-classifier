Slot 遊戲分類器使用說明

這份文件說明如何用 Claude Code 串聯完整競品截圖分類流程：從放入影片、自動截圖、ROI 人工確認、分類，到瀏覽器人工審核修正。

更新日期：2026-06-08 分支：main Python 3.10 Claude Code CLI CPU-only PaddleOCR
最快使用流程 資料夾用途 Claude 串聯流程 ROI 確認說明 人工審核操作 輸出結果說明 手動執行指令 常見問題

最快使用流程

1
把影片放入 project/input_videos/

支援 .mp4。影片名稱即為輸出資料夾名稱，建議用英文。

2
在專案根目錄啟動 Claude Code 
claude
3
告訴 Claude 開始分析 
幫我分析 WildTrain
4
在瀏覽器確認 ROI 邊框

Claude 給你連結後，用瀏覽器確認遊戲畫面邊框是否對齊，並回覆確認。

5
等待分類完成 → 在瀏覽器開 http://localhost:8765 進行人工審核

分類完成後 review server 自動啟動，對中低信心截圖進行複審，完成後按 Ctrl+C。

一般使用以上流程即可。若需要進階控制（指定 ROI 座標、單跑某一步），參考後面「手動執行指令」一節。

資料夾用途

位置用途

Claude 串聯完整流程

在專案根目錄執行 claude 後，輸入以下指令即可觸發完整流程：

幫我分析 WildTrain

Claude 會依序自動執行：

步驟動作說明
① 確認影片 project/input_videos/WildTrain.mp4 是否存在
② Auto ROI 偵測 自動找出遊戲畫面區域，生成 _debug/roi_adjust.html
③ 等待 ROI 確認 輸出 WAITING_ROI_CONFIRM:，等你在瀏覽器確認並回覆

⑤ 生成審核頁 generate_review_page.py → review.html
⑥ 啟動審核 Server http://localhost:8765 自動開起來
⑦ 回報結果 各類別截圖數量 + 需人工審核張數

ROI 確認說明

分類前需確認 ROI（遊戲畫面區域） 是否正確。ROI 偏移會讓分類器讀到影片外框，降低準確度。

如何確認

  1. Claude 給你 roi_adjust.html 路徑後，用瀏覽器開啟
  2. 檢查綠色邊框是否緊貼遊戲畫面（不含影片黑邊）
  3. 若需調整：拖曳四角或側邊調整範圍
  4. 按「✅ 確認 ROI」→ 座標自動複製到剪貼簿
  5. 貼回 Claude Chat 送出

回覆格式

需要調整時：

ROI 確認：400,50,650,950

邊框正確不需調整時：

ROI OK

座標格式：x, y, width, height（從左上角開始）

ROI 偵測是依據影片前段的動態畫面自動計算。若影片前段有片頭 logo 或靜態畫面，偵測框可能偏移，需要手動調整。

人工審核操作

分類完成後，Server 自動啟動，開瀏覽器前往 http://localhost:8765。

信心等級說明

等級意義標籤顏色建議動作
high 分類確定 🟢 綠色 直接跳過即可
medium 有把握但邊界模糊 🟡 黃色 快速掃一眼，有問題再修正
low 信心不足 🔴 紅色 建議確認，視情況改分類或排除

每張卡片的操作

按鈕動作
✅ 正確 標記確認，不移動檔案
🔀 改分類 從下拉選單選正確類別
🗑️ 排除 標記為排除（移到 excluded/）

右上角會顯示「待處理 N 張」，全部處理後按「套用修正」，系統自動移動截圖並更新 CSV。

若以 file:// 直接開啟 review.html（非 localhost），按下套用後會複製 JSON 到剪貼簿，需手動執行： 
.venv/bin/python apply_corrections.py --json '<貼上剪貼簿內容>'

輸出結果說明

分類完成後，主要輸出位於 project/output/<影片名>/：

輸出說明
Basegame/一般底層遊戲畫面（含 Spin、Auto、餘額 UI）
Feature game/Free Spin、Bonus 等特殊功能進行中

手動執行指令（不使用 Claude）

完整流程（含 ROI 確認）

# 步驟一：Auto ROI 偵測（看到 WAITING_ROI_CONFIRM 後停止）
bash classify_with_roi_confirm.sh --video-id WildTrain

# 步驟二：帶 ROI 座標重跑（含分類 + 審核頁 + 啟動 Server）
bash classify_with_roi_confirm.sh --video-id WildTrain --roi 400,50,650,950

直接指定 ROI（跳過偵測）

bash run_classify_roi.sh --video-id WildTrain --roi 400,50,650,950

單獨生成審核頁

.venv/bin/python app/generate_review_page.py project/output/WildTrain

單獨啟動審核 Server

.venv/bin/python review_server.py --video-id WildTrain
# 開瀏覽器前往 http://localhost:8765

套用修正（從 JSON 檔）

.venv/bin/python apply_corrections.py corrections.json

常見問題

Q: 分類完成但 review.html 是空的

.venv/bin/python app/generate_review_page.py project/output/WildTrain

Q: ROI 調整頁開啟後是空白

手動重新生成：

.venv/bin/python app/generate_roi_preview.py --video-id WildTrain

再用瀏覽器開啟：project/output/WildTrain/_debug/roi_adjust.html

Q: review server 啟動失敗（port 8765 已占用）

.venv/bin/python review_server.py --video-id WildTrain --port 8766

Q: 第一次跑很慢（等很久才開始處理）

PaddleOCR 首次執行會自動下載語言模型（約 300 MB），屬正常現象，後續不會重複下載。

Q: 分類速度很慢

調高取樣間隔降低工作量：

# app/constants.py
FRAME_INTERVAL = 30  # 預設 20，調高可加快速度

Q: 套用修正後 needs_review/ 仍有舊截圖

needs_review/ 是分類時的副本，apply_corrections 只移動主目錄的原始檔，副本可手動刪除，不影響 CSV 紀錄。

Q: Windows 下執行 .sh 腳本

使用 Git Bash 或 WSL 執行 .sh 腳本。或在 WSL 中直接執行 Python：

.venv/bin/python app/main.py --video-id WildTrain
