2. 安裝前準備

2.1 建議把專案放在短路徑

這個專案會安裝 PaddleOCR / PaddlePaddle，套件內部檔案很多、路徑也可能很長。Windows 如果路徑太深，安裝時容易出現「找不到檔案」或「Windows Long Path」相關錯誤。

建議路徑：
D:\slot_classifier_figma_share_package
C:\slot_classifier_figma_share_package
避免太深的路徑：
C:\Users\你的名字\Documents\很長的資料夾\很長的日期\很多層資料夾\slot_classifier_figma_share_package
路徑越深，安裝 PaddleOCR 時越容易失敗。

2.2 安裝 Python

建議使用 Python 3.10。目前專案使用的 PaddleOCR / PaddlePaddle 版本與 Python 3.10 搭配較穩定。

  1. 到 Python 官方網站下載 Python 3.10。
  2. 安裝時勾選 Add python.exe to PATH。
  3. 安裝完成後，打開 PowerShell，輸入下面指令確認版本。
python --version

如果看到類似 Python 3.10.x，代表 Python 已安裝成功。

3. 建立 Python 環境

以下步驟都在 PowerShell 執行。請先進入專案根目錄，也就是有 requirements.txt 的那一層。

3.1 切換到專案資料夾

如果你把專案放在 D:\slot_classifier_figma_share_package，請輸入：

cd D:\slot_classifier_figma_share_package

如果你仍使用目前這份工作資料夾，路徑會像這樣：

cd C:\Users\ashleyli\Documents\Codex\2026-04-30\files-mentioned-by-the-user-main\slot_classifier_figma_share_package
對外分享時，建議請同事先把資料夾移到短路徑，例如 D:\slot_classifier_figma_share_package，再開始安裝。

3.2 建立專案專用環境

請在專案根目錄執行：

python -m venv .venv

這會建立一個叫做 .venv 的資料夾。它是這個專案專用的 Python 環境，避免影響電腦上其他 Python 專案。

3.3 安裝需要的套件

先更新安裝工具：

.\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel

再安裝專案套件：

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

目前 requirements.txt 內主要包含：

numpy==1.26.4
opencv-python==4.6.0.66
paddlepaddle==2.6.2
paddleocr==2.7.3
這份安裝清單是 CPU 版本，不需要額外安裝顯卡或 CUDA。第一次安裝會下載較多套件，需要一些時間。

4. 確認環境是否正常

4.1 使用檢查腳本

專案根目錄有提供 check_environment.ps1，可以快速檢查常用套件是否能被載入：

.\check_environment.ps1

如果 PowerShell 不允許執行 .ps1，可以先改用下面的直接檢查指令：

.\.venv\Scripts\python.exe -c "import numpy, cv2, paddle, paddleocr; print('Python environment OK')"

看到 Python environment OK 就代表基本套件可以正常載入。

4.2 如果 PowerShell 阻擋 ps1 檔

有些電腦第一次執行 PowerShell 腳本會被系統阻擋。可使用以下指令允許目前使用者執行本機腳本：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

輸入後若出現確認問題，輸入 Y 後按 Enter。

5. 如何執行工具

5.1 影片分類工具 main.py

  1. 把影片放進 project\input_videos。
  2. 在專案根目錄執行分類程式。

使用腳本：

.\run_classifier.ps1

或使用完整 Python 指令：

.\.venv\Scripts\python.exe app\main.py

完成後，到 project\output 查看輸出結果。

5.2 Symbol 裁切工具 generate_symbol_table.py

如果已經跑過 main.py，Help 圖片會在 project\output\影片名稱或編號\Help 相關資料夾內。接著可以執行 Symbol 裁切工具：

.\.venv\Scripts\python.exe app\generate_symbol_table.py --video-id 8

--video-id 8 代表分析 project\output\8 這支影片的輸出資料。若影片資料夾叫做 Wild Train 或 Caishen Wins，可以改用對應名稱。

目前 generate_symbol_table.py 的目標是本地端產出 symbol icon 候選與最終裁切圖，不需要先串 Claude API。後續若要自動命名與整理報告，才需要再接 AI API。

6. 常見問題與注意事項

6.1 PaddleOCR 安裝失敗，出現 Windows Long Path

如果看到類似下面的錯誤：

Could not install packages due to an OSError
HINT: This error might have occurred since this system does not have Windows Long Path support enabled.

優先建議：

  1. 把整個專案移到短路徑，例如 D:\slot_classifier_figma_share_package。
  2. 刪除舊的 .venv。
  3. 重新建立環境並安裝套件。

如果仍失敗，可以請電腦管理者開啟 Windows 長路徑支援。用系統管理員身分開 PowerShell，執行：

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

執行後建議重新開機或至少重新開啟 PowerShell。

6.2 不建議直接複製別人的 .venv

雖然直接複製環境資料夾看起來很快，但 Python 虛擬環境內常會記錄原本電腦的路徑。換到另一台電腦後容易出現套件找不到、執行檔失效等問題。

對外分享時，建議分享專案資料夾與 requirements.txt，讓對方在自己的電腦上重新建立 .venv。

6.3 安裝套件時網路失敗

如果安裝時顯示連線錯誤，通常是公司網路、防火牆、VPN 或 Python 套件來源被擋。可以嘗試：

  1. 換到較穩定的網路。
  2. 關閉或切換 VPN。
  3. 請 IT 協助允許 Python / pip 下載套件。

6.4 Python 版本不對

如果使用 Python 3.12 或更高版本，PaddleOCR / PaddlePaddle 可能較容易遇到相容性問題。建議重新安裝 Python 3.10，並用 Python 3.10 建立 .venv。

6.5 NumPy 版本不相容

目前專案使用 numpy==1.26.4。這是為了避開部分 OpenCV / PaddleOCR 與 NumPy 2.x 的相容性問題。請不要自行升級到 NumPy 2.x。

6.6 輸出結果在哪裡

分類後的圖片會在：

project\output

常見分類資料夾包含：

  • Basegame
  • Feature game
  • Feature Buy
  • BigWin
  • Transition
  • Result
  • Help
  • loading
  • Other
  • low_score：低信心或備選結果，方便人工檢查。

7. 給分享對象的最短安裝流程

如果只想給同事一份最簡短的操作，可以提供下面這段：

  1. 把資料夾放到短路徑，例如 D:\slot_classifier_figma_share_package。
  2. 安裝 Python 3.10，並勾選 Add python.exe to PATH。
  3. 打開 PowerShell，切到專案資料夾。
  4. 執行 python -m venv .venv。
  5. 執行 .\.venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel。
  6. 執行 .\.venv\Scripts\python.exe -m pip install -r requirements.txt。
  7. 把影片放入 project\input_videos。
  8. 執行 .\.venv\Scripts\python.exe app\main.py。
  9. 到 project\output 查看結果。
下一步可做：再新增 .bat 檔，把常用指令包成「雙擊執行」版本，例如一個執行 main.py，一個執行 generate_symbol_table.py。
