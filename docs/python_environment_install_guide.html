1. 專案資料夾結構

從 GitHub 取得的專案結構如下：

slot-classifier/
├─ app/
│  ├─ pipeline.py              # 核心分類流程
│  ├─ scorers/                 # 各類別評分模組
│  │  ├─ classifier.py
│  │  ├─ confidence.py
│  │  ├─ bigwin_scorer.py
│  │  └─ ...
│  ├─ main.py
│  ├─ auto_roi.py
│  ├─ ocr_utils.py
│  ├─ config.py
│  ├─ constants.py
│  ├─ generate_review_page.py
│  └─ generate_roi_preview.py
├─ project/
│  ├─ input_videos/            # ← 放影片
│  └─ output/                  # ← 分類輸出
├─ review_server.py            # 本機審核 Server
├─ apply_corrections.py        # 套用人工修正
├─ classify_with_roi_confirm.sh # 主入口腳本
├─ run_classify_roi.sh
├─ requirements.txt
├─ check_environment.py
└─ CLAUDE.md                   # Claude Code 工作規則
位置用途
app/pipeline.py核心分類流程：截圖、OCR、評分、信心分數、CSV 輸出
app/scorers/各類別評分模組（若缺少此目錄，分類會失敗）
app/generate_review_page.py生成可在瀏覽器操作的 review.html 審核頁
review_server.py本機 HTTP Server，讓審核頁可以自動套用修正
apply_corrections.py接收修正 JSON，移動截圖並更新 CSV
classify_with_roi_confirm.sh主入口：ROI 偵測 → 確認 → 分類 → 審核頁 → Server
CLAUDE.mdClaude Code 啟動後自動載入的工作規則
project/input_videos/放入要分析的 .mp4
project/output/每部影片的分類截圖、CSV、審核頁

2. 安裝前準備

2.1 取得專案

git clone https://github.com/Ashley860511/slot-classifier.git
cd slot-classifier
git checkout perf/cpu-optimize-ocr

2.2 建議放在短路徑（Windows）

PaddleOCR 套件內部路徑很長，Windows 路徑過深容易導致安裝失敗。

建議路徑：
D:\slot-classifier
C:\slot-classifier
避免：
C:\Users\名字\Documents\很多層資料夾\slot-classifier

3. 安裝 Python 環境

3.1 安裝 Python 3.10

建議使用 Python 3.10，其他版本可能與 PaddleOCR 有相容性問題。

  1. 前往 python.org 下載 Python 3.10
  2. 安裝時勾選 Add python.exe to PATH
  3. 確認版本：python --version

3.2 建立虛擬環境

# macOS / Linux
python3.10 -m venv .venv
source .venv/bin/activate

# Windows PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1
若 PowerShell 阻擋 .ps1，先執行： Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

3.3 安裝套件

# 更新安裝工具
pip install --upgrade pip setuptools wheel

# 安裝專案套件（約 5～15 分鐘，視網路速度）
pip install -r requirements.txt

目前 requirements.txt 主要包含：

numpy==1.26.4
opencv-python==4.6.0.66
paddlepaddle==2.6.2
paddleocr==2.7.3
此為 CPU-only 安裝，不需要 GPU 或 CUDA。
首次執行分類時，PaddleOCR 還會自動下載語言模型（約 300 MB），屬正常現象。

4. 安裝 Claude Code CLI 新增

Claude Code 是串聯本工具完整流程的主要介面，安裝後只需用對話輸入指令即可完成分析。

4.1 安裝 Node.js（前置）

Claude Code 需要 Node.js 18 以上。前往 nodejs.org 下載 LTS 版本。

# 確認版本
node --version   # 需 v18 以上
npm --version

4.2 安裝 Claude Code

npm install -g @anthropic/claude-code

4.3 登入 Anthropic 帳號

claude login

依照提示在瀏覽器完成登入，回到終端後即完成。

4.4 確認安裝

claude --version
看到版本號碼代表 Claude Code 安裝成功。

5. 確認環境正常

python check_environment.py

輸出應顯示 Python、OpenCV、PaddleOCR 各套件版本無誤。

若無 check_environment.py，可手動確認：

python -c "import numpy, cv2, paddle, paddleocr; print('OK')"

6. 首次執行工具

方式 A：使用 Claude Code（推薦）

  1. 把影片放入 project/input_videos/WildTrain.mp4
  2. 在專案根目錄啟動：claude
  3. 輸入：幫我分析 WildTrain
  4. 依照 Claude 的指引確認 ROI、等待分類完成
  5. 分類完成後開瀏覽器：http://localhost:8765

方式 B：直接執行腳本

# Auto ROI 偵測
bash classify_with_roi_confirm.sh --video-id WildTrain

# 帶 ROI 座標直接分類
bash classify_with_roi_confirm.sh --video-id WildTrain --roi 400,50,650,950
Windows 使用者需透過 Git Bash 或 WSL 執行 .sh 腳本。
或直接用 Python 執行：python app/main.py --video-id WildTrain

7. 常見問題

PaddleOCR 安裝失敗：Windows Long Path

  1. 把專案移到短路徑，例如 D:\slot-classifier
  2. 刪除 .venv 後重新建立

若仍失敗，請系統管理員開啟 Windows 長路徑支援：

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
  -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force

PaddleOCR 分開安裝

pip install paddlepaddle==2.6.2
pip install paddleocr==2.7.3

不建議複製別人的 .venv

虛擬環境內記錄了原電腦的路徑，換機後容易失效。請在各自電腦重新建立 .venv。

npm install 失敗（公司網路）

嘗試切換網路或關閉 VPN，或使用公司內網的 npm registry。

Python 版本確認

python --version   # 需顯示 Python 3.10.x

若系統有多個 Python 版本，建立 venv 時明確指定：

python3.10 -m venv .venv

8. 最短安裝流程（對外分享版）

給同事的最短版本：

  1. 把專案放到短路徑，例如 D:\slot-classifier
  2. 安裝 Python 3.10，勾選 Add python.exe to PATH
  3. 安裝 Node.js 18+
  4. 開終端，進入專案資料夾： 
    cd D:\slot-classifier
git checkout perf/cpu-optimize-ocr
  5. 建立並安裝環境： 
    python -m venv .venv
.venv\Scripts\Activate.ps1
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
  6. 安裝 Claude Code： 
    npm install -g @anthropic/claude-code
claude login
  7. 把影片放入 project\input_videos\
  8. 啟動並分析： 
    claude
# 然後輸入：幫我分析 WildTrain
完成以上步驟後，後續每次使用只需進入專案資料夾執行 claude 即可。
